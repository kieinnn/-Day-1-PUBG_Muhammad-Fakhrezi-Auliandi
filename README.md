Secara umum, repository (atau sering disingkat repo) adalah tempat penyimpanan digital terpusat untuk menaruh, mengelola, serta mengatur berbagai berkas, data, atau kode sumber agar mudah diakses, dicari, dan digunakan kembali.
Tujuan dari repo sendiri untuk tempat penyimpanan digital terpusat untuk mengelola, mengatur, dan membagikan berbagai jenis file atau data secara aman.

Rangkuman Materi
Materi Building with AI, Managing Change with GitHub membahas Prompt Engineering, Git, GitHub, serta penggunaannya dalam proses pembuatan dan pengembangan aplikasi.

Prompt Engineering adalah cara merancang instruksi agar AI menghasilkan jawaban yang tepat, relevan, dan sesuai kebutuhan. Prompt merupakan masukan yang diberikan kepada AI, mulai dari pertanyaan sederhana hingga instruksi kompleks. Struktur prompt yang baik terdiri dari Role (peran AI), Task (tugas), Context (konteks), dan Format (bentuk hasil). Prompt yang spesifik dan memiliki konteks jelas dapat meningkatkan performa AI, mengurangi bias dan respons ofensif, meningkatkan kontrol serta prediktabilitas, dan memberikan pengalaman pengguna yang lebih baik.

Git adalah Version Control System (VCS) yang digunakan untuk melacak perubahan file, termasuk siapa yang mengubah, kapan perubahan dilakukan, dan apa yang diubah. Git diciptakan oleh Linus Torvalds pada tahun 2005. Sementara itu, GitHub merupakan platform berbasis web untuk menyimpan repository Git secara online dan mendukung kolaborasi. Git digunakan untuk mengelola perubahan secara lokal, sedangkan GitHub digunakan untuk menyimpan repository secara online.

Dalam Git terdapat tiga bagian utama, yaitu Working Directory, Staging Area, dan Git Directory. Working Directory merupakan tempat file proyek dikerjakan dan dimodifikasi. Staging Area adalah tempat mempersiapkan perubahan yang akan dimasukkan ke commit berikutnya. Git Directory merupakan tempat Git menyimpan metadata dan database objek proyek.

Beberapa konsep penting dalam GitHub adalah Repository, Commit, Branch, dan Pull Request. Repository merupakan tempat menyimpan proyek beserta riwayat perubahannya. Commit adalah catatan perubahan yang disimpan dalam repository. Branch merupakan cabang pengembangan yang memungkinkan pekerjaan dilakukan secara terpisah. Pull Request adalah permintaan untuk menggabungkan perubahan dari satu branch ke branch lainnya.

Poin Poin Penting
1. Prompt Engineering
- Prompt adalah instruksi atau masukan untuk AI.
- Struktur prompt: Role, Task, Context, Format.
- Prompt yang jelas dan spesifik menghasilkan jawaban yang lebih sesuai.
2. Git dan GitHub
- Git = Version Control System.
- GitHub = Platform penyimpanan repository Git secara online.
- Git diciptakan oleh Linus Torvalds pada tahun 2005.
3. Konsep Git
Istilah	Fungsi
Repository > Tempat menyimpan proyek dan riwayat perubahan
Commit > Menyimpan catatan perubahan
Branch	> Cabang pengembangan
Pull Request	> Permintaan penggabungan perubahan
Working Directory >	Tempat mengerjakan dan memodifikasi file
Staging Area >	Tempat mempersiapkan perubahan sebelum commit
Git Directory	> Tempat menyimpan metadata dan database Git

4. Setup dan SSH
- Install Git dan VS Code.
- Konfigurasi nama dan email Git.
- SSH Key digunakan untuk autentikasi GitHub.
- Verifikasi koneksi SSH menggunakan ssh -T git@github.com.
5. Alur Pengembangan Aplikasi
AI → Git → Commit → Push ke GitHub → Melakukan perubahan → Commit dan Push kembali.
